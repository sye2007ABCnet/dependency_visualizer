# Визуализатор графа зависимостей пакетов (вариант №19)

## Общее описание

CLI-инструмент для построения и визуализации графа зависимостей пакетов
Ubuntu (apt). Реализован на Python 3 без внешних зависимостей. Готовые
менеджеры пакетов и библиотеки для получения зависимостей не
используются. Работа выполняется поэтапно, каждый этап находится в
отдельной ветке.

## Функции и настройки

| Опция | Описание | По умолчанию |
|---|---|---|
| `-p`, `--package` | имя анализируемого пакета (обязательно) | — |
| `-r`, `--repo` | URL репозитория или путь к файлу тестового репозитория (обязательно) | — |
| `-t`, `--test-mode` | режим работы с тестовым репозиторием | выключен |
| `--package-version` | версия пакета (обязательна вне тестового режима) | — |
| `-o`, `--output` | имя файла с изображением графа (`.svg`) | `graph.svg` |
| `-a`, `--ascii-tree` | вывод зависимостей в виде ASCII-дерева | выключен |
| `-d`, `--max-depth` | максимальная глубина анализа (целое, ≥ 1) | `5` |

Каждый параметр проверяется. При ошибках выводятся сразу все найденные
проблемы, программа завершается с кодом 2.

### Этап 1

При запуске все параметры выводятся в формате `ключ=значение`.

## Сборка и запуск тестов

Сборка не требуется.

```bash
make test
make run ARGS="-p A -r fixtures/simple.txt -t"
```

Без `make`:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
python3 src/main.py -p A -r fixtures/simple.txt -t
```

## Скрипты ручной проверки

Запускаются из любого каталога, показывают команду и код завершения:

```bash
bash scripts/valid/stage1.sh      # корректные запуски
bash scripts/invalid/stage1.sh    # ошибки параметров
```

## Примеры использования

```
$ python3 src/main.py -p curl -r http://archive.ubuntu.com/ubuntu \
      --package-version 7.81.0-1ubuntu1 -a -d 3
package=curl
repo=http://archive.ubuntu.com/ubuntu
test_mode=False
version=7.81.0-1ubuntu1
output=graph.svg
ascii_tree=True
max_depth=3

$ python3 src/main.py -p Bad_Name -r archive -o g.png -d 0
ошибка: имя пакета 'Bad_Name' недопустимо: допускаются строчные латинские буквы, цифры и символы + - . (не короче 2 символов)
ошибка: 'archive' не является URL-адресом (ожидается http:// или https://)
ошибка: версия пакета обязательна вне тестового режима
ошибка: файл изображения 'g.png' должен иметь расширение .svg
ошибка: максимальная глубина должна быть не меньше 1
```
